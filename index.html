📝 About this app

This browser-based software lets you look at glyphs inside Minecraft Bedrock resource packs. You can search for specific characters, load multiple texture sheets, and copy glyphs directly to your clipboard. It simplifies the process of identifying special characters used in Minecraft fonts without needing advanced knowledge of game files.

🚀 How to use the glyph viewer

Once you finish the installation, you can open the viewer from your desktop. Follow these steps to load your glyphs:

  1. Open the application.
  2. Select the File menu at the top left of the window.
  3. Choose "Open Resource Pack" to find your folder.
  4. Select the folder containing your Minecraft texture files.
  5. The viewer displays the glyphs on the screen automatically.
  6. Use the search bar at the top to type in a specific unicode character.
  7. Click on any glyph to copy it to your clipboard for use in text editors or game commands.

⚙️ Loading multiple sheets

If your resource pack uses many sheets, you can load them all at once. Go to the "View" menu and select "Load Multi-sheet mode." This allows the application to reference all linked glyph files at the same time. The application identifies links between these files without manual input from you.
